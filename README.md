# Live Weather Card

A dynamic weather web app built with HTML, CSS, and Vanilla JavaScript using the Open-Meteo API.

## Iteration History

### Version 1: JUST WORKS
- Core prototype fetching weather for hardcoded coordinates.
- Plain HTML output without styling.

### Version 2: WORKS AND IS GOOD
- Dynamic worldwide city search via Geocoding API.
- Glassmorphism weather card UI.
- Modern `async/await` fetch logic with `try/catch` error handling.
